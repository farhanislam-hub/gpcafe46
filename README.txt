GP CAFÉ 46 — Restaurant Website
================================

Files:
- index.html
- style.css
- script.js
- assets/gp-cafe-46-concept.png

How to run:
1. Keep the folder structure unchanged.
2. Open index.html in Chrome/Edge.
3. The generated concept image is included locally.
4. Food/drink card photography currently uses remote Unsplash image URLs, so an internet connection is needed for those card images.

The site includes:
- Responsive desktop/mobile layout
- Racing-inspired black/red/gold theme
- Smooth scrolling
- Scroll reveal animations
- Loading screen
- Mobile navigation
- Hover/3D card effects
- Animated racing ticker and speed lines
- Your exact GP Café 46 menu names
